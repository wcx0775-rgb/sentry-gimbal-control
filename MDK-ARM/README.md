# robomaster

#### 介绍
上场的哨兵云台代码

## 简介
本套代码是使用了深圳北理莫斯科北极熊战队的电控开源框架的基础上进行了一系列的修改，开源链接：https://gitee.com/SMBU-POLARBEAR/StandardRobotpp
该代码是26年哨兵上场的代码，因为雷达没搞出来所以我是把路径写死了的。
## 配套套件
上位机调试软件：VOFA，该代码已经加上了相关的配置代码，可以直接调用函数使用

详细说明：
YAW轴：
使用的是DM4310，这里有个坑我没有搞，原本是可以直接用DM的串口助手直接更改电机位置的区间范围的，但是因为车已经装好了，再用串口太麻烦了，我就直接用软件的算法来弥补了，再来细说这个问题，当我的DM电机进行多圈转动的时候因为他的位置范围是-12.5到12.5，不是Π的整数倍，导致多圈转动的时候会精度缺失，进而导致电机的位置和理想的不一样，代码在gimbal_yaw_pitch_direct.c里的第355到366行

PITCH轴：
用的是dj的6020电机，说说pitch的问题，感觉pitch的响应不够快，控制的不是很完美，不知道是我代码问题，还是机械的问题导致我的pid很难调

双板通信：
双板用的是can1通信，注意这里的板id不要给错了，还有就是我原本是自己加了几个新的板id来用的，但是不知道为什么没有用，后面没办法就用的开源里的id，双板的发送函数就放在gimbal_task.c里的，没必要再去专门建一个双板通信的任务，暂时没有啥问题

上下位机通信：
没有用串口一大部分原因是因为串口不够了，正好开源是用的usb通信，就用着了，现在这个自瞄是同济很简单的一个自瞄，不是mpc那套，不过那套我也写了，也可以正常通信，想要的话可以找我要，但是视觉解算出来的角度好像有点问题，我也不懂，应该是视觉的问题，但我这个没加接收视觉的角加速度啥的，就是没有前馈，后面会加，不过大概率是要改成大小yaw了，雷达的代码我也已经写的差不多了，但是因为雷达这个赛季没搞出来，所以还有一些裁判系统的信息我没传给上位机，雷达搞出来了再加

发射机构：
开自瞄的时候发射权是完全交给自瞄的，还有就是我的哨兵有时候还会超射速，这我自己在备赛的时候测得没超的，比赛的时候就超了，说明我的摩擦轮也是有点问题的，剩下的自己看吧

还有一个点就是陀螺仪解算的代码，因为这套代码使用了卡尔曼滤波，所以给单片机的计算量有点大，后面如果自己要根据这套代码再自己重新写新的要记得在cubemx里把最小栈和最小堆大小给加大，不然单片机解算不出欧拉角和四元数

因为我一开始是先写的底盘代码，上板的代码是底盘代码复制后改的，所以代码会有些冗余，后面自己看着改进吧
